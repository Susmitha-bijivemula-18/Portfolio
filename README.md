# Susmitha Portfolio 🚀

A modern, high-performance portfolio for **Bijivemula Susmitha** — Full Stack Developer specialized in React.js, TypeScript, Java, and Spring Boot.

## ✨ Highlights
- **Hero Section**: Dynamic left-aligned typography, live video background, and fast-action CTAs.
- **About Me**: Interactive code window with live-typing animation and technical capability badges.
- **Technical Skills**: High-velocity dual-row continuous marquee stream with tab filtering and hover pause.
- **Production Projects**: Staggered scroll-reveal animation with embedded live demo previews and GitHub repositories.
- **Engineering Pipeline**: Single-row horizontal CI/CD pipeline visualizing the development workflow:
  $$\text{Claude AI} \longrightarrow \text{Cursor IDE} \longrightarrow \text{Antigravity} \longrightarrow \text{GitHub} \longrightarrow \text{Vercel} \longrightarrow \text{Render}$$
- **Resume Modal**: Interactive in-browser CV preview and direct download.
- **Design System**: Fully responsive with seamless Light / Dark mode toggling and accessible motion.

## 🛠️ Tech Stack
- **Frontend**: TypeScript, HTML5, Vanilla CSS
- **Tooling**: Vite, TypeScript Compiler (`tsc`)
- **Hosting**: Vercel (Frontend), Render (Backend APIs)

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
